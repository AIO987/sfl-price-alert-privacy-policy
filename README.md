# SFL Price Alert — Privacy Policy

This repository hosts the public Privacy Policy for the SFL Price Alert Android application.

## GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Replace `REPLACE_WITH_SUPPORT_EMAIL` in `index.html` with a monitored support email before publishing.

Once GitHub Pages is enabled, the policy URL will be:

https://aio987.github.io/sfl-price-alert-privacy-policy/

Use that URL in the Google Play Console Privacy Policy field after confirming the page is published and publicly accessible.
